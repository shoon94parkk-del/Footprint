# Footprint

공개 인터넷에 흩어진 자기 자신의 디지털 흔적을 한 번에 재구성하는 self-audit 웹앱입니다.

## MVP
- 이름 필수, 회사/학교/직무/지역/GitHub ID/추가 키워드 선택
- 공개 웹 + 특허 관련 결과 + Crossref + GitHub 공개 프로필 탐색
- 동명이인 오판을 줄이기 위한 힌트 기반 신뢰도 점수
- Digital Footprint Score, 자동 요약, 카테고리별 흔적, 타임라인
- 입력값/검색 결과 DB 저장 없음

## Run
```bash
npm start
```

## Privacy
현재 버전은 이메일/전화번호를 입력받지 않습니다. 결과는 공개 정보의 자동 추정이며 원문 확인이 필요합니다.
